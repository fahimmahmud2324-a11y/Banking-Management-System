Banking Transaction Management System is a console-based application developed in C as a Data Structures course project. 
The system manages customer accounts and banking transactions using fundamental data structures.

Data Structures Used:

i)   Linked List — Account management
ii)  Queue — Pending transaction processing using FIFO
iii) Stack — Transaction history and undo operations

Key Features:

i) Create and manage accounts
ii) Deposit and withdrawal requests
iii) FIFO-based transaction processing
iv) Transaction history tracking
v)  Undo the latest completed transaction
vi) View accounts and pending transactions
vii) Basic time complexity analysis
